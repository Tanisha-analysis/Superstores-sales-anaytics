# Superstore Sales Analysis
Sales and Profit Analysis using Excel and SQL

## Tools Used
Excel Pivot Tables, Conditional Formatting

## Key Insights from Day 4
1. Tables subcategory: $207K sales but -$17.7K loss - highest loss
2. Bookcases: -$3,472 loss and Supplies: -$1,189 loss 
3. Copiers most profitable: $55.6K with 37% profit margin
4. Finding: High sales ≠ high profit. Discount impact to be checked next
